# Web Search Router — Claude Skill

Маршрутизатор по 8 каноническим задачам веб-поиска для Claude Code и Claude Desktop. Помогает агенту выбрать правильный инструмент (Exa, Tavily, Firecrawl, Apify, AnySite, Brave, Parallel и др.) и **блокирует случайный запуск дорогих режимов** (Exa Websets, Parallel FindAll, Exa /research, Parallel Deep Research) до явного подтверждения пользователя.

## Что внутри

- `SKILL.md` — собственно сам скилл (~250 строк markdown с YAML-frontmatter)

## 8 канонических задач, которые покрывает скилл

| # | Задача | Главный инструмент |
|---|---|---|
| 1 | Найти информацию по смыслу (семантический поиск) | Exa |
| 2 | Найти информацию по точному запросу (keyword) | Tavily / Brave |
| 3 | 🛑 Глубокое исследование (deep research) | Parallel / Exa /research |
| 4 | Получить актуальные события | Tavily / Brave / AnySite (Telegram) / Apify (соцсети) |
| 5 | Прочитать конкретную страницу | Exa / Firecrawl (для JS) |
| 6 | Обойти весь сайт (crawling) | Firecrawl / Apify |
| 7 | Взаимодействовать со страницей (browser automation) | Firecrawl / Apify |
| 8 | 🛑 Собрать структурированный список объектов | Apify / AnySite / Exa Websets / Parallel FindAll |

🛑 — задачи с дорогими режимами под защитой согласования.

## Установка

### Шаг 1: скопируйте папку `web-search-router/` в ваш каталог скиллов

**Windows (Claude Desktop / Claude Code):**
```
C:\Users\<ваше-имя>\.claude\skills\web-search-router\
```

**macOS / Linux:**
```
~/.claude/skills/web-search-router/
```

Внутри должен быть файл `SKILL.md` (а также этот `README.md`).

### Шаг 2: перезапустите Claude

- **Claude Desktop** — полностью выйти через системный трей и запустить заново
- **Claude Code** — закрыть и открыть терминал

Скилл подцепится автоматически и будет вызываться, когда вы просите Claude найти / поискать / спарсить / собрать список и т.п.

## Подключённые MCP, которые скилл умеет использовать

Скилл рассчитан на следующие MCP — но работает и без полного набора (просто будет рекомендовать только то, что у вас подключено):

- ✅ **Exa** — `https://mcp.exa.ai/mcp` (или официальный коннектор)
- ✅ **Tavily** — официальный MCP
- ✅ **Firecrawl** — `https://mcp.firecrawl.dev/...`
- ✅ **Parallel AI** — кастомный MCP
- ✅ **Apify** — расширение `ant.dir.gh.apify.apify-mcp-server`
- ✅ **AnySite** — `https://mcp.anysite.io/mcp`
- ✅ **Brave Search** — локально через `npx @modelcontextprotocol/server-brave-search` (нужен бесплатный API-ключ)

Опциональные (упомянуты в скилле, но требуют отдельной оплаты):
- ⚙️ Perplexity Sonar — минимум $50 на API
- ⚙️ NewsCatcher — от $250/мес
- ⚙️ Serper — бесплатный тир 2500 запросов
- ⚙️ Jina AI Reader — без ключа

После установки новых MCP **обновите блок «Статус подключений»** в `SKILL.md` (раздел 3-й сверху) под себя.

## Как скилл защищает от дорогих режимов

Перед запуском любого из:
- Exa Websets API
- Exa `/research` endpoint
- Parallel FindAll API
- Parallel Deep Research

…скилл **обязан** вывести красное сообщение `🚨🚨🚨 PAY ATTENTION 🚨🚨🚨` с оценкой стоимости, дешёвыми альтернативами и уточняющими вопросами. Согласием считается **только** явная фраза «ДА, ЗАПУСКАЙ + имя инструмента». «Ок» / «давай» / «продолжай» — не считается.
